RackTracker

파워랙에 붙이는 3D 동작 분석 장치

파워랙에 고정한 글로벌 셔터 카메라 3대가 전기 신호 한 줄로 같은 순간을 찍습니다. 각 영상에서 찾은 관절을 세 방향에서 교차하되, 한 방향이 가려지면 나머지로 살려 cm 단위 3D 좌표를 계산합니다.

세트마다 무게중심 이동, 좌우 비대칭, 상체 기울기, 스쿼트 깊이를 기록해 회원과 트레이너에게 돌려줍니다. 판정 기준은 회원마다 신체 비율로 따로 잡습니다.

촬영 조건이 늘 같아 지난 회차와 새 세션을 같은 기준으로 비교합니다. 처리는 랙 옆 컴퓨터가 폐쇄망에서 끝내므로 회원 영상이 헬스장 밖으로 나가지 않습니다.

pipeplot

Neural networks,
built layer by layer
in walkable space.

모델마다 페이지가 하나씩 있습니다. 모델 페이지는 실제로 학습된 가중치와 activation을 3D 공간에 세워 보여 주고, 개념 페이지는 한 사람이 개념을 이해해 간 순서대로 장면을 쌓습니다.

지금은 AlexNet, VGG-16, GoogLeNet, ResNet-34 네 모델과 개념 페이지가 있습니다. 앞으로 ML/DL 학습과 커뮤니티의 장으로 넓혀 갑니다.

Claude Code 저장소용 workflow와 backstop
